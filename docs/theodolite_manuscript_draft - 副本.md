# 考虑经纬仪倾角安全约束的机械臂末端测量位姿规划与仿真验证

> 说明：本文为北大核心期刊论文初稿，已根据当前代码实验结果撰写“摘要、引言、方法、实验、结果分析”部分。文中 `[文献X]` 为待检索、待核验引用占位，后续需替换为真实参考文献。

## 摘要

面向卫星测量任务的机械臂辅助测量系统中，经纬仪等姿态敏感载荷通常安装于机械臂末端。与一般末端执行器不同，经纬仪在运动过程中不仅要求到达指定测量位置，还需满足由工作姿态、机械安装边界和观测精度共同决定的倾角安全约束。针对传统机械臂轨迹规划方法侧重末端位置可达、缺少载荷姿态全过程约束的问题，本文提出一种考虑经纬仪倾角安全约束的机械臂末端位姿规划方法。该方法以 KUKA KR20 六自由度机械臂为对象，建立经纬仪等效刚性载荷的末端倾角模型，将末端位置误差、载荷竖直轴偏差、关节连续性、关节限位距离和倾角越界惩罚统一纳入非线性最小二乘优化框架，并结合任务空间直线插值和 cubic smoothstep 时间参数化生成连续轨迹。在 MuJoCo 平台中构建仿真实验，对 100 个随机采样目标点进行规划与伺服跟踪验证，并与仅位置逆运动学和关节空间插值两类传统方法进行对比。结果表明，本文方法在 100 个目标点中实现 99 个规划可达、98 个完整成功，完整成功率为 98.0%，最大观测倾角为 14.36 deg，显著低于 45 deg 安全阈值；而仅位置逆运动学和关节空间插值方法的完整成功率分别为 20.0% 和 31.0%，最大观测倾角分别达到 83.47 deg 和 110.45 deg。倾角阈值扫描进一步表明，在当前采样空间与控制参数下，当要求保持 98/100 的基准完整成功数时，最小测试倾角阈值为 15 deg。研究结果说明，本文方法能够在保证目标点定位精度的同时有效抑制经纬仪载荷倾斜，为卫星测量任务中的机械臂辅助测量位姿规划提供了一种可复现的仿真验证框架。

**关键词**：机械臂；经纬仪；卫星测量；姿态约束；轨迹规划；逆运动学；MuJoCo

## 1 引言

卫星地面测量、装调和测试任务对测量设备的空间位置与姿态稳定性提出了较高要求。经纬仪作为典型光学测量设备，常用于目标方位角、俯仰角及空间几何关系的测量，其工作可靠性与载荷安装姿态密切相关。在传统测量场景中，经纬仪多采用固定支架、三脚架或专用工装进行安装，测量位置调整依赖人工搬运或机械平台移动。随着机器人技术在航天装调、柔性制造和智能测试领域的应用不断扩展，利用机械臂携带经纬仪完成多测点测量成为提高测量自动化程度和空间适应能力的重要途径[文献1-3]。

然而，机械臂末端携带经纬仪执行测量任务时，其规划目标不同于普通搬运或抓取任务。一方面，机械臂末端需要到达给定测量点，以满足测量视线、空间布局或工艺流程要求；另一方面，经纬仪属于姿态敏感载荷，运动过程中如果末端发生过大倾斜，可能影响仪器内部光机结构、安装稳定性和后续观测精度。对于卫星测量任务而言，末端轨迹规划不能仅以目标点位置误差作为评价依据，还应关注运动全过程中载荷相对竖直方向的倾角变化。若轨迹规划算法只保证末端位置可达，而忽略经纬仪载荷姿态，则可能出现目标点到达精度满足要求但运动过程中倾角越界的情况，从而削弱任务安全性和测量可靠性。

现有机械臂运动规划研究主要围绕逆运动学求解、轨迹平滑、避障约束、动力学可行性和最优控制等方面展开[文献4-7]。在实际工程应用中，常见方法包括基于逆运动学的点到点规划、关节空间插值、采样型路径规划以及轨迹优化方法。此类方法在末端位置可达性、关节运动连续性或避障能力方面具有较好表现，但对于经纬仪这类具有明确姿态安全边界的末端载荷，仍存在两方面不足：其一，部分方法将末端姿态作为目标位姿的一部分处理，但缺少针对载荷倾角安全阈值的全过程约束描述；其二，部分平滑插值方法能够降低关节突变，却无法保证载荷姿态在运动中始终处于安全范围内。因此，有必要建立面向经纬仪载荷的倾角约束模型，并将其与末端精度、关节连续性和关节限位要求共同纳入规划过程。

针对上述问题，本文提出一种考虑经纬仪倾角安全约束的机械臂末端测量位姿规划方法。方法以六自由度 KUKA KR20 机械臂为研究对象，将末端可视化模型等效为刚性经纬仪载荷，通过载荷局部竖直轴与世界竖直轴的夹角定义倾角安全指标。在规划层面，本文构建包含位置误差、姿态偏差、关节连续性、限位距离和倾角越界惩罚的非线性最小二乘优化问题；在轨迹层面，采用任务空间直线插值和 cubic smoothstep 参数化生成路径点序列，并以上一路径点关节角作为迭代初值，以增强关节轨迹连续性。为验证方法有效性，本文在 MuJoCo 仿真平台上进行多目标点采样实验、传统方法对比实验和倾角阈值极限扫描实验。

本文的主要贡献如下：

1. 面向卫星测量任务建立机械臂末端经纬仪等效刚性载荷倾角约束模型，将经纬仪工作姿态、机械安装安全边界和观测精度需求转化为可计算的末端倾角约束。
2. 提出一种同时考虑末端定位精度、载荷倾角安全、关节连续性和关节限位的约束逆运动学规划方法，实现测量载荷运动全过程姿态安全控制。
3. 构建可复现的 MuJoCo 仿真实验流程，从多采样点约束满足性、传统方法对比、轨迹顺滑性和倾角极限阈值等方面验证方法性能。

## 2 经纬仪载荷姿态约束建模与规划方法

### 2.1 机械臂末端经纬仪载荷建模

本文采用 KUKA KR20 六自由度串联机械臂作为仿真对象。机械臂关节变量记为

```math
\mathbf q=[q_1,q_2,q_3,q_4,q_5,q_6]^T
```

末端执行点位置记为

```math
\mathbf p_e(\mathbf q)=[x_e,y_e,z_e]^T
```

目标测量点位置记为

```math
\mathbf p_d=[x_d,y_d,z_d]^T
```

在仿真模型中，经纬仪载荷与机械臂末端采用刚性连接。为便于观测载荷姿态变化，模型中使用透明圆柱体和轴线标记表示经纬仪等效刚性载荷。该几何外观仅用于可视化，不参与液体动力学、夹爪接触或真实光机结构分析。经纬仪载荷局部竖直轴由两个 site 点确定，分别记为载荷轴线底点和顶点：

```math
\mathbf p_b(\mathbf q),\quad \mathbf p_t(\mathbf q)
```

则载荷局部竖直单位向量为

```math
\hat{\mathbf z}_{l}(\mathbf q)=
\frac{\mathbf p_t(\mathbf q)-\mathbf p_b(\mathbf q)}
{\|\mathbf p_t(\mathbf q)-\mathbf p_b(\mathbf q)\|}
```

世界坐标系竖直方向定义为

```math
\hat{\mathbf z}_{w}=[0,0,1]^T
```

经纬仪载荷倾角定义为二者之间的夹角：

```math
\theta(\mathbf q)=
\cos^{-1}\left(\hat{\mathbf z}_{l}(\mathbf q)^T\hat{\mathbf z}_{w}\right)
```

根据经纬仪工作姿态、机械安装安全边界和观测精度约束，设置最大允许倾角为

```math
\theta(\mathbf q)\leq \theta_{\max}
```

在基准实验中，取

```math
\theta_{\max}=45^\circ
```

该约束表示机械臂携带经纬仪运动过程中，载荷局部竖直轴相对世界竖直方向的偏离不得超过安全阈值。

### 2.2 约束逆运动学优化模型

对于给定目标点，规划目标是在关节限位范围内求得一组关节角，使末端尽可能到达目标位置，并保持经纬仪载荷姿态安全。本文将规划问题构造为非线性最小二乘问题。位置残差定义为

```math
\mathbf r_p=w_p(\mathbf p_e(\mathbf q)-\mathbf p_d)
```

其中，`w_p` 为位置误差权重。载荷姿态残差采用载荷竖直轴与世界竖直轴的叉乘表示：

```math
\mathbf r_o=w_o(\hat{\mathbf z}_{l}(\mathbf q)\times\hat{\mathbf z}_{w})
```

当两轴方向一致时，叉乘向量趋近于零。该项用于引导经纬仪载荷在规划过程中保持接近竖直方向。

为提高相邻路径点之间的连续性，引入关节连续性残差：

```math
\mathbf r_c=w_c(\mathbf q-\mathbf q_{prev})
```

其中，`\mathbf q_{prev}` 为上一轨迹点的关节角。该项能够抑制关节角在相邻路径点之间突变，是本文评价和改善轨迹顺滑性的关键组成部分。

为避免关节角过度接近机械限位，引入关节限位残差：

```math
\mathbf r_l=w_l
\frac{\mathbf q-\mathbf q_{mid}}
{\mathbf q_{max}-\mathbf q_{min}}
```

其中，`\mathbf q_{min}` 与 `\mathbf q_{max}` 分别为关节下限和上限，`\mathbf q_{mid}` 为关节限位中值。

为显式处理倾角安全边界，定义倾角越界惩罚项：

```math
r_s=w_s\max(0,\theta(\mathbf q)-\theta_{\max})
```

当载荷倾角未超过阈值时，该项为零；当倾角超过阈值时，该项随越界量增大而增加。

综合上述残差，本文求解如下优化问题：

```math
\min_{\mathbf q}
\left\|
\begin{bmatrix}
\mathbf r_p\\
\mathbf r_o\\
\mathbf r_c\\
\mathbf r_l\\
r_s
\end{bmatrix}
\right\|_2^2
```

约束条件为

```math
\mathbf q_{min}\leq\mathbf q\leq\mathbf q_{max}
```

该优化问题采用 SciPy `least_squares` 求解。与只考虑末端位置的逆运动学方法相比，本文方法将经纬仪姿态安全作为规划过程中的显式优化目标和安全边界，从而能够在到达目标点的同时降低运动过程中的倾角风险。

### 2.3 轨迹生成与顺滑性处理

设机械臂初始末端位置为 `\mathbf p_0`，目标位置为 `\mathbf p_d`。本文采用任务空间直线插值生成末端路径：

```math
\mathbf p(s)=(1-s)\mathbf p_0+s\mathbf p_d
```

其中，`s` 由 cubic smoothstep 函数给出：

```math
s(t)=3t^2-2t^3,\quad t\in[0,1]
```

该时间参数化在起点和终点处具有零速度特性，有助于降低路径端点附近的突变。对每个离散路径点，以上一路径点关节角作为当前求解初值进行约束逆运动学求解，得到关节轨迹序列：

```math
\mathbf q_0,\mathbf q_1,\ldots,\mathbf q_N
```

为定量评价轨迹顺滑性，本文统计关节路径长度、最大关节步长、RMS 关节速度和 RMS 关节加速度。关节路径长度定义为

```math
L_q=\sum_{k=1}^{N}\|\mathbf q_k-\mathbf q_{k-1}\|_2
```

离散关节速度和加速度分别为

```math
\dot{\mathbf q}_k=\frac{\mathbf q_k-\mathbf q_{k-1}}{\Delta t}
```

```math
\ddot{\mathbf q}_k=\frac{\dot{\mathbf q}_k-\dot{\mathbf q}_{k-1}}{\Delta t}
```

其中，`\Delta t` 为相邻控制指令之间的时间间隔。RMS 加速度越小，说明关节运动整体越平缓；最大关节步长越小，说明相邻路径点之间突变越弱。

## 3 仿真实验设计

### 3.1 仿真平台与参数设置

本文基于 MuJoCo 构建 KUKA KR20 机械臂仿真平台。模型包含六个转动关节、末端经纬仪等效刚性载荷、目标点标记、地面、相机和位置伺服驱动器。机械臂各关节由 position actuator 驱动，规划得到的关节角序列作为控制输入进行伺服跟踪。仿真中记录末端实际位置、载荷最大倾角、最终位置误差、关节角轨迹和顺滑性指标。

基准实验主要参数如下：

| 参数 | 数值 |
|---|---:|
| 目标点数量 | 100 |
| 随机种子 | 42 |
| 倾角安全阈值 | 45 deg |
| 最终位置误差阈值 | 0.02 m |
| 规划路径点数 | 45 |
| MuJoCo 时间步长 | 0.001 s |
| 每个规划点仿真子步数 | 30 |
| 末端稳定步数 | 2000 |

目标点在机械臂前方可达空间内随机采样。采样半径、方位角和高度分别在预设范围内均匀生成，并剔除不满足前方工作空间要求的点。每个目标点先经过规划器生成关节轨迹，若规划成功，则进入 MuJoCo 位置伺服跟踪仿真。

### 3.2 评价准则

本文将完整任务成功定义为同时满足两个条件：

```math
\|\mathbf p_e(T)-\mathbf p_d\|_2\leq0.02\ \text{m}
```

```math
\max_t \theta(t)\leq\theta_{\max}
```

其中，第一项表示最终目标点定位精度满足要求，第二项表示运动全过程中经纬仪载荷倾角不超过安全阈值。若目标点能够规划出轨迹但仿真跟踪后倾角越界，则视为任务失败；若最终误差超过阈值，也视为任务失败。

### 3.3 对比方法设置

为验证本文方法的必要性，设置两类传统规划基线：

1. **Position-only IK**：仅优化末端位置误差，不显式考虑经纬仪倾角约束，也不强调相邻路径点关节连续性。该方法用于模拟只关注目标点到达精度的传统逆运动学规划。
2. **Joint interpolation**：先对目标点求解一次仅位置逆运动学，再在初始关节角与目标关节角之间进行 smoothstep 关节空间插值。该方法用于模拟关节轨迹较平滑但缺少载荷姿态安全约束的规划思路。

三种方法使用相同目标点集合、相同机械臂模型和相同仿真参数。对比指标包括完整成功率、最终误差、最大观测倾角和 RMS 关节加速度。

### 3.4 倾角阈值极限扫描

为分析经纬仪倾角约束的可行下限，本文进一步设置 5 deg、10 deg、12 deg、14 deg、15 deg、20 deg、30 deg 和 45 deg 共 8 组倾角阈值进行扫描实验。每组实验均使用相同 100 个目标点和相同随机种子，统计规划成功数、完整成功数、最大成功倾角、平均成功误差和轨迹顺滑性指标。该实验用于回答在当前机械臂构型和采样空间下，若要保持基准成功率，倾角约束可以收紧到何种程度。

## 4 结果分析

### 4.1 多采样点约束满足性

基准实验中，本文方法在 100 个采样目标点上实现 99 个规划可达，其中 98 个目标点在 MuJoCo 伺服跟踪后同时满足最终误差和倾角约束，完整成功率为 98.0%。成功样本的平均最大倾角为 1.54 deg，最大成功倾角为 14.36 deg，显著低于 45 deg 安全阈值。成功样本的最大最终误差为 0.0168 m，满足 0.02 m 误差约束。

采样点三维分布与约束满足性如图 `outputs/paper_runs/figures_100/sampling_constraint_3d.png` 所示。结果表明，本文方法在机械臂前方不同高度和不同横向位置的目标点上均表现出较好的适应性。个别失败目标点主要与边界工作空间附近的可达性和伺服跟踪误差有关，而不是倾角约束越界导致。该结果说明，将经纬仪载荷倾角纳入规划过程并未显著牺牲整体可达性。

### 4.2 与传统规划方法的对比

三种方法的 100 点对比结果如表 1 所示。

**表 1 三种规划方法的仿真结果对比**

| 方法 | 规划成功数 | 完整成功数 | 完整成功率 | 有限仿真平均误差/mm | 最大观测倾角/deg | 倾角越界样本数 | RMS 加速度中位数/(rad/s²) |
|---|---:|---:|---:|---:|---:|---:|---:|
| 本文方法 | 99/100 | 98/100 | 98.0% | 5.01 | 14.36 | 0 | 2.52 |
| Position-only IK | 52/100 | 20/100 | 20.0% | 5.07 | 83.47 | 32 | 68.60 |
| Joint interpolation | 60/100 | 31/100 | 31.0% | 5.11 | 110.45 | 29 | 1.98 |

由表 1 可知，三种方法在有限仿真样本中的平均最终误差接近，均约为 5 mm，说明仅从最终位置误差角度观察，传统方法似乎也能完成部分目标点到达任务。但进一步比较最大观测倾角可以发现，Position-only IK 和 Joint interpolation 在运动过程中均出现明显倾角越界，最大观测倾角分别达到 83.47 deg 和 110.45 deg，远超 45 deg 安全阈值。相比之下，本文方法最大观测倾角仅为 14.36 deg，且无倾角越界样本。

该对比说明，机械臂携带经纬仪执行卫星测量任务时，仅以末端位置误差评价规划结果是不充分的。Position-only IK 能够在部分目标点上获得较小最终误差，但由于缺少载荷倾角项，其关节解可能导致经纬仪在运动中大幅倾斜。Joint interpolation 的 RMS 加速度中位数为 1.98 rad/s²，略低于本文方法的 2.52 rad/s²，说明其关节轨迹在数值上较平滑；但该方法完整成功率仅为 31.0%，且最大倾角达到 110.45 deg，表明轨迹平滑并不等价于载荷姿态安全。本文方法在保持较低 RMS 加速度的同时，将倾角控制在安全范围内，实现了精度、安全性与顺滑性的综合平衡。

方法对比图见 `outputs/paper_runs/figures_100/method_comparison_metrics.png`，顺滑性剖面图见 `outputs/paper_runs/figures_100/smoothness_profile.png`。从图中可以看出，Position-only IK 的 RMS 加速度显著高于另外两种方法，说明仅位置优化容易造成关节序列跳变；Joint interpolation 虽然顺滑，但由于缺少经纬仪姿态约束，在安全性上不能满足任务要求；本文方法在完整成功率和最大倾角指标上具有明显优势。

由表 2 可知，在当前采样空间和控制参数下，倾角阈值从 45 deg 收紧到 15 deg 时，完整成功数仍保持 98/100，与基准阈值下结果一致。当阈值继续收紧到 12 deg 和 14 deg 时，完整成功数降为 97/100；当阈值收紧到 5 deg 或 10 deg 时，完整成功数为 95/100。该结果表明，本文方法在多数目标点上能够将经纬仪倾角控制在较小范围内，并具有较大的安全裕度。

需要指出的是，5 deg 阈值下最大观测倾角仍可能超过 5 deg，但这些越界样本不计入完整成功数。因此，从工程应用角度看，若要求保持与 45 deg 基准实验相同的 98/100 完整成功数，当前实验条件下最小测试阈值为 15 deg；若允许完整成功率降低到 95.0%，则 5 deg 阈值仍能完成 95 个目标点。该结果为后续根据不同经纬仪型号、安装结构和观测精度要求选择倾角安全边界提供了依据。

### 4.4 结果讨论

综合上述实验结果，本文方法的优势主要体现在三个方面。首先，本文方法将经纬仪倾角安全约束嵌入逆运动学优化过程，而非在规划后进行事后检查，因此能够在路径生成阶段主动规避姿态越界。其次，本文方法通过关节连续性项和 smoothstep 时间参数化抑制相邻路径点突变，使轨迹在保持姿态安全的同时具有较好的关节连续性。再次，倾角极限扫描表明，本文方法不仅能满足 45 deg 工程安全阈值，还能在更严格阈值下保持较高成功率，说明该方法具有一定安全裕度。

本文实验也存在一定局限。第一，当前模型将经纬仪载荷视为刚性连接体，尚未考虑末端安装柔性、夹持误差和经纬仪内部光机结构。第二，仿真中主要验证机械臂运动规划和伺服跟踪可行性，尚未引入真实经纬仪测量误差传播模型。第三，本文对比方法选取了仅位置逆运动学和关节空间插值两种典型基线，后续可进一步加入采样型规划、模型预测控制或完整轨迹优化方法进行更广泛比较。第四，当前实验基于仿真环境，仍需在实物机械臂和经纬仪平台上开展进一步验证。

尽管存在上述限制，本文结果已经表明，对于卫星测量任务中的姿态敏感载荷，规划算法必须同时考虑末端位置精度、载荷姿态安全和关节轨迹顺滑性。本文提出的约束逆运动学规划框架具有实现简单、指标可解释、仿真可复现等特点，可作为后续实物系统开发和测量闭环控制研究的基础。
