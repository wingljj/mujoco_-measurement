# 经纬仪测量主题论文与 pgfplots 图组重构设计

## 1. 目标与边界

将论文从“机械臂持杯运输与防倾洒”统一重构为“机械臂末端刚性安装经纬仪，在多个目标测站之间转移，并通过约束逆运动学抑制运输倾斜，为到位稳定后的精度测量提供可靠初始姿态”。同步重写正文、图题和图引用，并以统一的 LaTeX/TikZ/pgfplots 体系重绘 8 张图。

本次工作保留现有机械臂轨迹、逆运动学和 MuJoCo 仿真数据，不修改或伪造实验结果。由于没有具体经纬仪型号、标定数据或“倾角—角秒误差”模型，论文只把倾角、加速度、Jerk 和角速度解释为测量准备姿态与稳定恢复负担的代理指标，不量化测量精度提升。

## 2. 科学叙事

论文的核心论点为：机械臂将末端刚性安装的经纬仪移动至多个目标测站；约束逆运动学在满足目标位置要求的同时抑制仪器竖轴相对重力方向的偏离，使经纬仪到达后具有更小的整平与稳定恢复负担，为后续静止测量提供可靠初始姿态。

经纬仪只在机械臂到达目标位姿并稳定后执行测量，运动过程中不执行测量。因此，正文不得把运输倾角直接解释为在线测量误差。可讨论的风险包括重新整平负担、标定状态变化风险、到位稳定时间和测量准备姿态一致性。

### 2.1 术语映射

| 原术语 | 统一术语 |
|---|---|
| 持杯运输 | 机械臂持经纬仪测站转移 |
| 杯体竖直轴 | 经纬仪竖轴 |
| 倾洒风险 | 测量准备姿态风险 |
| 防止液体溢出 | 避免过大倾斜引起重新整平、标定状态变化及测量精度风险 |
| 动态倾洒代理指标 | 运输动态扰动代理指标 |
| 液体晃动或 Jerk | 仪器振动与稳定恢复负担或 Jerk |

### 2.2 阈值解释

- 45°仅作为算法搜索和机械运输的粗粒度安全上限，不是经纬仪测量精度标准。
- 10°作为本文采用的保守运输姿态阈值，用于重点展示姿态裕度。
- 两个阈值均为研究设定，不宣称是行业标准或具体仪器允许值。
- 现有数据仅支持减小到达前姿态扰动和重新整平风险，不直接证明测量精度提高了具体数值。

## 4. 全局视觉规范

建立公共样式文件 `figures/pgfplots/jmechplots.sty`，各图通过同一入口加载：

- 每张图使用 `\documentclass{standalone}`，以 XeLaTeX 编译并获得紧裁剪 PDF。
- 默认单栏宽 8 cm、双栏宽 15 cm；每张图定义可覆盖的 `\FigWidth` 与 `\FigHeight`。
- 图内文字全部使用中文，全局视觉字号为 8 pt；中文优先使用本机可嵌入的宋体/黑体，数学和单位保持规范直立/斜体关系。
- 坐标轴采用封闭框线，轴线宽 0.7 pt，刻度向内，主刻度长 3 pt，次刻度长 1.5 pt。
- 数据线统一约 0.8–1.0 pt。系列同时使用低饱和深蓝、深红、暗绿、黑色，以及实线、虚线、点画线和空心圆/方/三角标记，保证灰度打印可辨。
- 默认不显示网格；确需网格时使用极细浅灰虚线。
- 图例背景透明、无边框或极细灰边，优先放置于图内数据空白区域。
- 单位放在坐标轴标签中，避免在刻度值中重复；小数位根据原始数据精度统一。

## 8. 验证与验收

实施完成需满足：

- 8份 TeX 均由 XeLaTeX 无错误编译，且没有缺失引用或字体替代警告影响中文显示。
- PDF MediaBox 与设计尺寸一致并紧裁剪；600 DPI PNG 的像素尺寸与物理尺寸相符。
- 中文字体嵌入，线宽、刻度方向、字体大小、图例和配色符合公共样式。
- 图5–8的关键数值与源 CSV 逐项或聚合复核；失败样本的纳入规则与正文一致。
- 图8两种方法按相同 seed/target 配对，单位统一为 mm 和度。
- 全文扫描“杯、倾洒、液体、晃动”等旧主题词；仅允许在明确说明旧模型限制或引用原始实现命名时出现。
- 扫描“测量精度提高”“精度损失量”等强因果措辞，确保没有超出现有证据。
- 人工检查每张 PNG 的裁剪、标签遮挡、图例覆盖、字号一致性和灰度可辨性。
